# 이커머스 고객 이탈(Churn) · 리텐션 분석

## 문제 정의
이커머스 서비스에서 신규 고객 획득 비용은 점점 오르는 반면, 기존 고객의 이탈을 조기에
감지하고 방어하는 것은 상대적으로 저렴하고 효과적인 성장 레버다. 이 프로젝트는 다음
질문에 답하기 위해 실제 대규모 행동 로그를 분석한다.

1. 고객은 언제, 얼마나 이탈하는가? (코호트 잔존율)
2. 구매 전환 과정에서 어디서 이탈이 발생하는가? (퍼널 분석)
3. 이탈 위험 세그먼트를 어떻게 정의하고, 리텐션 캠페인의 효과를 어떻게 검증할 것인가? (A/B 테스트 설계)

핵심은 "정확도 높은 예측 모델"이 아니라, **비즈니스 문제를 정의하고 데이터로 검증 가능한
형태로 푸는 과정**을 보여주는 것이다.

## 데이터
- 출처: Kaggle 공개 데이터셋 [eCommerce behavior data from multi category store](https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store) — [REES46 Marketing Platform](https://rees46.com/) 제공
- 기간: 2019-10 ~ 2020-04 (월별 CSV 7개, 이벤트 약 2.85억 건 / 총 약 56GB)
- 원본은 로컬 외부 저장 장치에서 **읽기 전용으로 참조**하며 저장소에는 포함하지 않는다. 경로는 하드코딩하지 않고 `config.py`의 `DATA_DIR`로 주입한다.
- 스키마 (9개 컬럼):

| 컬럼 | 설명 |
|---|---|
| event_time | 이벤트 발생 시각 (UTC) |
| event_type | view / cart / remove_from_cart / purchase |
| product_id | 상품 ID |
| category_id | 카테고리 ID |
| category_code | 카테고리 코드 (결측 32.2%, 01_eda 확인) |
| brand | 브랜드 (결측 14.0%, 01_eda 확인) |
| price | 가격 |
| user_id | 사용자 ID |
| user_session | 세션 ID |

⚠️ 파일당 5~9GB로 매우 크다. 전체를 메모리에 올리지 않고, 필요한 컬럼만 선택 + dtype
최적화 + 필요 시 user_id 기준 샘플링(5~10%)으로 처리한다 (`src/load.py`).

## 방법론
- **코호트 분석**: 사용자의 첫 활동(또는 첫 구매) 월을 기준 코호트로 삼고, 경과 개월 수별
잔존율을 히트맵으로 시각화. 여러 달 데이터가 필요하므로 파일을 이어붙이거나 샘플링해서 사용.
- **퍼널 분석**: `user_session` 단위로 view → cart → purchase 도달 여부를 플래그화하여
단계별 전환율을 계산. (당초 `remove_from_cart` 이벤트로 장바구니 이탈을 볼 계획이었으나,
EDA 결과 보유한 7개월 데이터 전체에 `remove_from_cart` 이벤트가 존재하지 않아 제외.
대신 "장바구니에는 담았지만 같은 세션에서 구매로 이어지지 않은 비율"로 장바구니 이탈을
우회 측정.)
- **이탈(churn) 정의**: 마지막 활동 이후 N일 무활동을 이탈로 정의. 04_churn_features에서
7개월 전체 재방문 간격을 재검증해 **N = 30일로 확정**했다 (90번째 percentile인 35일에
근접한 라운드 넘버 + 이커머스에서 통용되는 "30일 비활성=이탈" 룰과 부합).
`config.py`의 `CHURN_INACTIVITY_DAYS = 30`.
- **우측 절단(right-censoring) 처리**: 데이터 종료일 근처에 유입된 유저는 "아직 이탈할
시간이 없었을 뿐"이므로 이탈 여부를 확정할 수 없다. 종료일에서 30일을 뺀 시점을 기준으로
그 이전 활동 이력이 있는 유저만 판정하고, 최근 30일 내 신규 유입 유저는 `censored`
(판단 보류)로 분리해 이탈률 집계에서 제외한다.
- **A/B 테스트 설계**: 실제 실험 대신, 이탈 위험 세그먼트를 대상으로 한 리텐션 캠페인의 A/B
테스트 설계 문서(대상 정의, 지표, 표본 크기 산정, 실험 기간, 검정 방법)를 작성.

## 진행 상태
- [x] 프로젝트 스캐폴딩
- [x] `src/load.py` 로딩 유틸 구현 (`load_month`, `load_months`)
- [x] 01_eda (1~4단계): 데이터 구조·기간·이벤트 분포·결측 확인
  - 각 파일은 파일명이 가리키는 월 전체를 정확히 커버
  - 이벤트 비율(10~11월 기준): view 94.9% / cart 3.6% / purchase 1.5%
  - `remove_from_cart` 이벤트 없음 → 퍼널 설계 조정 (위 참고)
  - 결측치: `category_code` 32.2%, `brand` 14.0%
- [x] 01_eda (5단계): 유저·세션 단위 통계
  - 유저당 이벤트 수: 중앙값 5회 / 평균 20.7회 (헤비유저·봇 추정 극단치 존재)
  - 유저당 세션 수: 중앙값 2회 / 평균 4.3회, 세션당 이벤트 수: 중앙값 2회
  - 재방문 간격: 중앙값 3일 / 평균 6.5일, 75%가 8일 이내 재방문 (2달 스냅샷 기준)
  - `user_session`(UUID)은 3개 컬럼만으로도 6.6GB — 세션 관련 작업 시 category dtype 검토 필요
- [x] 02_cohort_retention: 7개월 전체, 첫 활동(view 포함)월 기준 코호트 잔존율 히트맵
  - 코호트 크기(신규 유저): 10월 302만 → 11월 370만 → 12월 458만 → 1월 439만 → 2월 423만 → 3월 411만 → 4월 451만
  - 1개월차 잔존율이 코호트가 최신일수록 하락: 10월 46% → 11월 36% → 12월 26% → 1월 23% → 2월 23% → 3월 20%
  - 가설: 11~12월 블랙프라이데이/연말 시즌 특가로 일회성 방문자가 대거 유입되며 신규 유입은 늘었지만 재방문 의향이 낮은 유저 비중이 커져 잔존율이 하락한 것으로 추정
  - 구현 시 미래(미관측) 코호트×경과개월 조합은 0%가 아니라 NaN으로 처리해 히트맵에서 제외 (예: 2020-04 코호트는 아직 1개월차 데이터가 없음 — 0%로 표시하면 오독 소지)
- [x] 03_funnel: 7개월 전체 + 월별, 세션 단위 view→cart→purchase 퍼널
  - 전체 퍼널: 세션 9,030만 → cart 1,097만(12.1%) → purchase(cart 경유) 490만(cart의 44.7%)
  - 장바구니 이탈률 55.3%
  - **데이터 이상치**: "cart 기록 없이 구매만 있는 세션" 비율이 10월 53.6%, 11월 16.2%로 유독 높고 12월부터는 0.4~7.2%로 급감 — 실제 행동 변화라기보다 데이터 수집 초기의 cart 이벤트 로깅 불안정 가능성. 월별 전환율 그래프의 10~11월 급변도 이 영향으로 추정되어 "계절성"으로 해석 시 주의 필요
- [x] 04_churn_features: 이탈 기준일 확정 + 우측 절단 반영 라벨링 + RFM 피처 생성
  - 재방문 간격 7개월 전체 재검증(4,459만 건): 중앙값 4일 / 평균 12.7일 / 90%가 35일 이내. 2달 스냅샷(중앙값 3일)보다 평균·상위 구간이 크게 늘어, **짧은 관찰 기간은 장기 재방문 패턴을 과소평가**함을 확인 → `CHURN_INACTIVITY_DAYS = 30` 확정
  - 우측 절단 처리: 최근 30일 내 신규 유입 유저 211만 명을 `censored`로 분리해 이탈률 집계에서 제외
  - 이탈률: 평가 가능한 유저 1,353만 명 중 **82.3%가 이탈**로 확정
  - 구매 경험 여부가 재방문을 가름: 재방문(retained) 유저의 31.5%가 구매 경험이 있는 반면 이탈(churned) 유저는 10.3%에 그침 → 위험 세그먼트를 재방문 빈도뿐 아니라 **구매 경험 여부로도 나눠야 함**을 시사
  - 생성 피처: `status`(churned / retained / censored), `recency_days`, `active_days`, `active_months`, `purchase_count`, `purchase_days`, `total_spend`, `is_buyer`, `repeat_buyer`, `cohort_month`
- [ ] 05_ab_test_design: 진행 중 — RFM 위험 세그먼트 대상 리텐션 캠페인 A/B 설계
  - 대상 세그먼트: 위험군 중 구매 경험자(`is_buyer=true`) — 04의 재방문율 3배 차이에 근거
  - 가설: 이탈 임박(recency 20~30일) 구매 경험자에게 개입하면 30일 재방문율이 상승한다
  - 지표: 30일 재방문율(primary) / 구매 전환율·객단가(secondary) / 이탈률(guardrail)
  - 성공 기준과 표본 크기는 측정 전에 사전 정의 (분석 후 기준을 맞추지 않기 위함)
