# 리텐션 캠페인 A/B 테스트 설계

이 문서는 실제 캠페인 결과가 아니라, REES46 공개 데이터 분석을 바탕으로 한 사전 설계안이다.

## 대상과 배정

- 기준 시점: 2020-03-31
- 위험군: 최근 활동 후 15~29일이 지난 사용자
- 규모: 약 220만 명
- 층화 변수: 구매 경험 여부(`is_buyer`)
- 배정: 각 층 안에서 사용자 단위 무작위 배정

데이터 종료일 기준의 `recency_days`로 위험군을 뽑으면 이미 재방문한 사용자가 섞이는 순환논리가 생긴다. 따라서 결과 관찰 전인 기준 시점으로 recency를 다시 계산한다.

## 처치와 지표

- 처치군: 개인화 리마인드 1회
- 대조군: 기존 안내 유지
- 할인 정책: 두 군 동일
- Primary: 시작일로부터 30일 이내 재방문율
- Secondary: 구매율, 객단가
- Guardrail: 수신 거부율, 할인 비용, contribution margin

## 표본 크기와 성공 기준

- 유의수준 0.05, 검정력 0.80
- 최소검출효과: 절대 +5%p
- 검정: two-proportion z-test
- 전체 baseline 25.95% 기준 그룹당 1,276명
- 구매 경험군 baseline 47.60% 기준 그룹당 1,568명
- 비구매군 baseline 21.79% 기준 그룹당 1,152명

통계적 유의성만으로 성공을 선언하지 않는다. Primary의 실질 기준을 충족하고 Guardrail이 악화되지 않아야 한다. 세그먼트별 추가 검정은 탐색적으로 해석하고, 확정 판단이 필요하면 다중비교 보정을 적용한다.

## 한계

- 공개 데이터이므로 실제 수신 동의 여부와 캠페인 비용을 관찰할 수 없다.
- 구체적인 채널과 인센티브는 실제 서비스의 정책·비용 구조에 맞춰 다시 정해야 한다.
- 산출된 표본 크기는 설계 기준이며 실제 실험 성과가 아니다.
